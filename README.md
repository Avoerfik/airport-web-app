# ✈️ ИС «Аэропорт» — Расписание рейсов и продажа авиабилетов (`_PAG8`)

Веб-приложение информационной системы аэропорта, разработанное в рамках расчётного задания по дисциплине «Базы данных».

## 🛠 Технологический стек
* **СУБД:** PostgreSQL 15 с расширением `plpython3u` (хранимые процедуры, функции, триггеры на все таблицы, представления, роли, B-tree индексы).
* **Бэкенд:** Python 3, FastAPI, гибридный слой доступа к данным:
  * **DB-API (`psycopg2`)** — для выполнения всей бизнес-логики БД (`CALL` хранимых процедур и `SELECT` из `VIEW` и табличных функций);
  * **ORM (`SQLAlchemy`)** — исключительно для управления учётными записями пользователей и ролевой авторизацией (JWT).
* **Фронтенд:** React 18, TypeScript, Vite, Tailwind CSS.
* **Инфраструктура:** Docker / Docker Compose.

## 👥 Ролевая модель и учётные записи
* **Администратор (`admin` / `admin123`)** — полный доступ: управление рейсами и тарифами, регистрация пользователей, финансовая аналитика рейсов, просмотр журнала триггерного аудита.
* **Диспетчер (`dispatcher` / `disp123`)** — создание рейсов, изменение статусов и базовых тарифов, удаление рейсов (с триггерной защитой вылетевших рейсов).
* **Кассир (`cashier` / `cashier123`)** — регистрация пассажиров, оформление и возврат билетов с учётом зонирования салона.
* **Пассажир (`passenger` / `pass123` или самостоятельная регистрация)** — поиск рейсов на табло, онлайн-покупка и возврат своих билетов.

## 📂 Структура репозитория
```text
├── db/
│   ├── Dockerfile               # Образ PostgreSQL 15 + postgresql-plpython3-15
│   ├── 01_schema.sql            # Схема БД в 3НФ (7 таблиц), ограничения, индексы
│   ├── 02_views_and_roles.sql   # Представления (VIEW) и роли уровня СУБД
│   ├── 03_functions.sql         # Скалярные, табличные и PL/Python-функции
│   ├── 04_procedures.sql        # Хранимые процедуры (INSERT / UPDATE / DELETE)
│   ├── 05_triggers.sql          # Триггеры контроля целостности и аудита на все 7 таблиц
│   └── 06_seed.sql              # Начальное заполнение БД через хранимые процедуры
├── backend/                     # Серверное API (FastAPI + DB-API + ORM)
├── frontend/                    # Клиентское приложение (React + TypeScript + Tailwind)
└── docker-compose.yml           # Конфигурация контейнера БД
```

## 🚀 Инструкция по запуску

1. **Запуск базы данных (Docker):**
   ```bash
   docker compose up --build -d
   ```

2. **Запуск бэкенда (FastAPI):**
   ```bash
   cd backend
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   ./venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

3. **Запуск фронтенда (React + Vite):**
   ```bash
   cd frontend
   npm install
   npm run dev -- --host 0.0.0.0
   ```
   Приложение будет доступно по адресу `http://localhost:5173`.
