# ?? Аэропорт: Информационная система расписания рейсов

Проект представляет собой полноценное веб-приложение (Fullstack), разработанное на основе лабораторных работ по дисциплине «Базы данных». 
Реализует клиент-серверную архитектуру, ORM-моделирование и современный пользовательский интерфейс.

## ?? Стек технологий
*   **База данных:** PostgreSQL 15
*   **Бэкенд:** Python 3.10+, FastAPI, SQLAlchemy (ORM), Pydantic
*   **Фронтенд:** React 18, TypeScript, Vite, Tailwind CSS
*   **Инфраструктура:** Docker (для БД)

## ?? Структура проекта
```text
??? db/               # SQL-скрипты (схема БД и тестовые данные)
??? backend/          # Серверная часть (FastAPI + ORM)
??? frontend/         # Клиентская часть (React + Tailwind)
??? docker-compose.yml # Конфигурация для запуска PostgreSQL
